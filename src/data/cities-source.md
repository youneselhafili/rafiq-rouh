# Morocco location catalog

Expanded from 43 to 393 Moroccan cities, directly administered communes and urban centers using HCP RGPH 2024.

Source: https://www.hcp.ma/file/242341/
Publication: https://www.hcp.ma/Population-legale-du-Royaume-du-Maroc-repartie-par-regions-provinces-et-prefectures-et-communes-selon-les-resultats-du_a3975.html

Imported standalone communes with geographic-code subdivision 01 and rows labeled "dont le centre urbain", plus Sale (aggregate commune code). Existing entries and their identifiers were retained; equivalent Arabic or Latin names were deduplicated. This is a city/urban-center catalog, not a list of every rural commune or village. Homonymous entries are currently represented once.

All Moroccan entries use AlAdhan method 21 and Africa/Casablanca. Existing Yabiladi fallback identifiers are preserved; newly imported entries do not have a Yabiladi fallback. API geocoding depends on the city name. Live smoke checks covered Sale, Temara, Ouarzazate, Guelmim, M'diq, Tinghir, Berrechid and Tata, not every imported location.
